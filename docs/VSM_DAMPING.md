# 追加減衰D₁・D₂

既存のドループ由来のDdroop=ωbase/Kp=50に、独立した比例減衰D₁とウォッシュアウト型過渡減衰D₂を加えます。全4機に同じ追加係数を使用します。

```text
ν = (ωinternal − ωbase)/ωbase
M νdot = Pset − Pcap − Ddroop ν − D1 ν − D2(ν − z)
zdot = ωD(ν − z)
δdot = ωbase ν
M = τp Ddroop = 2H
```

D₁は一定の内部周波数偏差にも作用し、定常の有効ドループ勾配は1/(Ddroop+D₁)になります。D₂の伝達関数はD₂s/(s+ωD)で、周波数偏差が一定ならz→νとなり追加出力は0になります。両者とも固定基準周波数からの内部周波数偏差を入力とします。PLL周波数との差を用いる方式ではありません。

D₂は各機1個、合計4個の動的状態zを持ちます。追加減衰が有効な場合の積分系は56微分状態＋14代数変数です。公開する66状態の観測・従来チェックポイントは従来座標へ戻し、zは別途保存します。D₁=D₂=0のときは従来の52微分状態＋14代数変数をそのまま積分します。

## 設定

| 環境変数 | 既定値 | 意味 |
|---|---:|---|
| VSM_D1 | 0 | 追加比例減衰、pu電力/pu周波数 |
| VSM_D2 | 100 | 追加過渡減衰の高周波ゲイン、同上 |
| VSM_OMEGA_D | 50 | フィルタ極、s⁻¹。時定数0.02秒、折点約7.96 Hz |

D₁,D₂は非負有限、ωDは正有限である必要があります。既定値のD₁=0は比例減衰を無効にする設定です。機構は実装済みで、環境変数で有効にできます。D₂=100は過渡減衰を有効にします。これらは設定例であり、この系統で最適化した値ではありません。

両機構を有効にする例：

```bash
VSM_D1=10 VSM_D2=100 VSM_OMEGA_D=50 \
OPENBLAS_NUM_THREADS=1 JULIA_NUM_THREADS=1 \
julia --project=provenance --startup-file=no code/run.jl damping_smoke.csv
```

この例ではM,Hは従来どおり、有効定常ドループは1/60≈1.667%になります。D₂はその定常勾配には加算されません。

旧結果を再現するには、新しい出力ディレクトリ・ケース名でVSM_D1=0 VSM_D2=0を指定します。環境変数を変更した後はJuliaを再起動してください。

## 初期化・イベント・再開

独立した計算の初期値はz=νとし、開始時の不要な過渡減衰キックを避けます。周波数のステップに対するウォッシュアウト応答を検証する場合は、solve_vsmのwashout_state引数でzを指定できます。

共通segmentは各段の`*_washout_end.csv`へzを保存し、事故投入・除去や観測区間の継続時に値を引き継ぎます。`*_damping.csv`はD₁,D₂,ωDの順の3行です。完了済み区間を再利用する際もzを復元します。別の探索入口のバイナリキャッシュにもzを含めます。途中区間から開始してzが取得できない場合、共通segmentは停止します。

再開署名には追加係数とコードを含め、旧キャッシュや異なる追加係数の混在を拒否します。旧生成結果は退避し、新しいケース名・空の出力先を使ってください。

`solve_vsm`は66状態のuに加えて各保存時刻のwashoutを返します。自作の分割積分では、次区間へwashout_state=前区間.washout[end]を渡してください。

平衡点の位置はν=0,z=0では変わりません。事故前後の安定性判定は、追加した4状態を含むJacobianのSchur補元を使います。古いDroop固有値を追加減衰系の安定性とみなさないようにしています。

## 出典と適用範囲

[WECC公開REGFM_B1仕様書・図2](https://www.wecc.org/sites/default/files/documents/products/2024/Virtual%20Synchronous%20Machine%20Grid-Forming%20Inverter%20Model%20Specification-REGFM_B1.pdf)のD₁比例減衰とD₂ウォッシュアウト減衰の機構を、現行詳細DAEに追加しています。REGFM_B1全体のモデルへ置換するものではありません。現行の回路・PI・電流指令制限は保持しています。

D₁,D₂を加えるとDroopとの厳密な軌道等価性はなくなります。既存のDroop保存図表は追加減衰の結果を表しません。D₂による減衰改善や脱調抑制は、設定した系統条件ごとに再計算して判断してください。

## 検証結果（2026-11-04）

- 従来の座標変換・Droop等価性：77項目合格（追加減衰を明示的に無効化）。
- 追加減衰：15項目合格。比例減衰の符号・作用、一定周波数偏差に対するウォッシュアウトの解析解、分割積分時のメモリ引継ぎ、係数入力検査を確認。
- D₁=10、D₂=100、ωD=50 s⁻¹で事故前・事故中・事故後30秒が全てSuccess。
- 各事故イベントの前区間終端zと次区間初期zが完全一致。保存係数・66+4状態の形式、代数残差1e-8未満を確認。
- 非VSM部分269ファイルのGit blobハッシュ一致とJulia構文・差分の空白検査を確認。

Julia 1.12.5、1スレッド、元の固定依存環境で実行。全300～1000秒計算・全領域探索や、減衰係数の最適化は今回の検証には含めません。
