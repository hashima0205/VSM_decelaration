# Bus5電圧を補償したH=2.5秒での回転例（2026-11-04）

## 条件と結果

ユーザー指定に基づき、Bus5の並列容量性サセプタンスによって事故前電圧0.98 pu以上を確保する条件を必須とした。Bを単に微小な正値へ変更したケースではない。

## 調整と採否の考え方

- Bは公称周波数での定サセプタンス。元の定インピーダンス負荷へQ_load_p=−B×vref2を設定し、事故前・事故中・事故後とも保持。容量性注入はQcap=B|V5|²となる。
- 元のk=1.0299のままでは、B追加後の事故後根を安定枝に沿って追跡できなかった。通常Newton法の失敗を「根が存在しない証明」とは扱わない。失敗ログは別study h2p5_bus5_capacitor_searchに保持。
- 事故後の局所安定平衡点との共存を調べるため、既存の補償検討で用いられたB=1、k≈0.681273を候補とした。kの変更は線路4–6・5–6のR/Xだけを元のkとの比で変更する。トポロジーは同じ。
- 負荷のGは変更していないが、定インピーダンス負荷のため電圧上昇とともに実消費Pは変わる。
- 事故前0.98 pu以上を条件にした。事故後も常に0.98 pu以上という条件ではない。
- B=1 puは設定例であり、実機の補償容量の最適化・妥当性を実証するものではない。モデルの電力ベースと実機定格の対応は別途必要。

## 平衡点と数値検証

- 事故前根の最大固有値実部：-0.00183158207 s⁻¹。事故後根：-0.00183237919 s⁻¹。追加減衰の状態を含む全モデルで双方が局所安定。
- Julia 1.12.5、Rodas5P、rtol=1e-9、atol=1e-11。基準dtmax=0.005秒と細分化dtmax=0.00125秒を比較。
- 遠方平均回転数の差：1.824e-10回転。両計算で遠方3機がnegative_running。
- 最大代数残差：7.216e-14以下。
- 各イベントでD2のフィルタ状態を引き継ぐ。前段終端と次段初期の差は監査表で確認。
- 有限1000秒の確認であり、無限時間の回転の証明ではない。系統条件は追跡された折返しに近いので、広い運転範囲に一般化しない。
