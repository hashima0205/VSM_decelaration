# 隠れ状態と回転の原因の診断

2026-11-05。D1=10の基準回転例と、事故除去時にR56を25%低減した回復例を比較し、未表示の状態差、近傍平衡点、状態置換による帰結の変化を検討した。

## 要点

**今回の差は、未表示のPI積分器やQフィルタに巨大な差が隠れていたという説明より、Bus5基準では見えにくい共通の内部位相・速度の差と整合する。** ただし、下記は特定時刻の状態置換であり、制御機構そのものの無効化試験ではない。

- 約2.99秒で遠方平均内部角は基準−1.82335 rad、R低減例−1.48164 rad。差は約0.342 rad（19.6°）。
- 基準系統の事故後安定点は−1.66968 rad、近傍の鞍点は−1.70122 rad。安定点–鞍点間の遠方平均内部角差は約1.81°。
- 同じ2点をBus5基準へ投影すると0.175582 / 0.175302 radで、差は約0.000280 radしかない。Bus5基準の位相図では、共通位相の不安定方向が強く圧縮される。
- PI・Qフィルタ・D2状態を回復例の値に置換しても回転。内部角・速度を回復例に合わせる置換と、全状態置換では回復した。

## A. 未表示状態の比較

[内部状態比較 PNG](hidden_states.png) / [PDF](hidden_states.pdf) / [同時刻の数値](comparison_points.csv)

複素回路量は各GFMの内部角で回転させた座標でも比較し、固定座標での位相移動を振幅・内部状態の差と混同しないようにした。PI積分状態γd/qは制御器内のdq成分のまま比較する。

4.99秒で、遠方3機の平均端子電圧は基準0.9784 pu、回復例0.9931 pu。一方Bus5電圧は0.8070 / 0.9106 pu。GFM電圧そのものが大きく崩れた差より、負荷母線までのネットワーク電圧降下の差が大きい。

2.99秒でQf平均は基準0.27325、回復例0.16118 pu。Q–Vドループ係数0.05を用いると、このQf差に対応する電圧指令差は約0.00560 pu。端子・負荷電圧の差すべてを、この電圧指令差だけで説明することはできない。

同時刻の最大|Qf−Qcap|は基準約0.000419、回復例約0.001557 puで、回復例の方が大きい。Qフィルタ遅れの大きさだけで回転を説明する結果ではない。D2の時定数も1/50=0.02秒で、今回の状態置換では1000秒の帰結は変わらなかった。

## B. 同じ回路での状態置換試験

置換時刻は絶対2.99秒（事故除去後1.84秒）。全ケースで**基準回転例の元のR/X・H・D1=10・D2=100・B5=1**を使用した。回復例の指定した状態だけを移植し、14代数変数を整合化してから1000秒積分した。実機操作の提案ではなく、状態の役割を調べる仮想介入である。

位相を伴う置換には注意が必要である。「内部角・速度」の試験では、内部角を変えたときに既存のVc・Ig・Ifの複素成分も同じ角度だけ回転し、元の内部角座標での電圧・電流を保持した。従って、δとνだけの2変数置換と解釈しない。「電気状態だけ」の試験は逆に、回復例のVc・Ig・Ifを基準例の内部角へ整合させて移植した。

この結果は、2.99秒に存在するPI等の値の差を単独で消しても回転が消えず、共通位相・速度を含む状態群を変えると帰結が変わることを示す。別の時刻、別の振幅の置換、KqやPIゲインを持続的に変更する介入までは検証していない。Q–V連成の寄与を否定する試験ではない。

## C. 安定点の近くの鞍点と不安定モード

[平衡点投影比較](equilibrium_projections.png) / [平衡点の数値](equilibrium_comparison.json) / [根の探索・固有値](root_scan.csv)

基準系統の近傍鞍点は、全モデルの定常残差約4.2e−12、追加減衰状態を含む縮約56状態の正の固有値が1個、λ≈+0.08153 s⁻¹で確認した。単なるNewton法の別候補ではなく、不安定性を検証した定常根である。

鞍点まわりの線形化で左固有ベクトルを求め、全56状態差の不安定モードへの寄与を分解した。2.99秒で基準例と回復例の投影差は、主に共通内部角と周波数の項に現れ、PIやQフィルタの寄与差はそれより小さかった。保存データ：mode_projection.csv / unstable_mode.csv / saddle_jacobian.csv。

**このモード投影は局所的な補助診断で、符号を厳密な大域的引き込み領域の境界とは扱わない。** 回復例はRが異なるため、基準鞍点の線形化を回復例へ適用した値も比較用の投影に過ぎない。2次元の位相投影で鞍点を通過したことだけを、完全な状態空間での境界通過の証明とはしない。

## D. 現時点で考えられる機構

1. 事故除去直後は両例の52微分状態＋4フィルタ状態が同じ。しかし、Rが違うため代数整合化後の端子電圧は同一ではない。
2. LCLフィルタの系統側電流式は、同じ回路内部状態でも端子電圧差の影響を受ける。モデルでは `(Lg/ω0) dIg_r/dt = Vc_r−Ug_r−Rg Ig_r+Lg Ig_i`（虚部も同様）。端子電圧差が電流の変化率を変え、Pcap/Qcapと周波数応答に差が蓄積する経路がある。
3. 基準例はslackとの共通位相ずれを残し、内部角・速度を含む不安定方向へ離れる。Bus5も同時に動くため、Bus5相対位相だけではこの変化を捉えにくい。
4. 位相・電圧状態の違いに伴い、連系線電流・無効電力吸収、Bus5電圧、コンデンサ供給、電気出力が変化し、基準例では再減速と周期回転へ進む。

「未観測のあるPI積分器が暴走し、それが回転を起こす」との証拠は今回の試験からは得られなかった。一方で、ネットワークと電圧・無効電力の連成を不要とする結論でもない。直接操作で帰結を変えた状態群と、同時に変化する観測量を区別している。

## 数値・データ

- 全9置換条件を1000秒、Rodas5P、rtol=1e−9、atol=1e−11、dtmax=0.005秒で計算。
- 元の52状態・追加4状態を保持し、指定群だけを変更して代数整合化。初期値・変更添字を条件別フォルダに保存。
- 基準条件の再開計算、各群置換、全状態履歴、機別分類、最初10秒の観測を保存。分類は既存の機別・複数時間窓基準。回復は位相・周波数の判定で全状態の完全収束を意味しない。
- 残差・固有値・局所左右固有ベクトルの関係を検査。有限時間の結果であり永久回転の証明ではない。
- run.jl 1/2/3：置換試験。mode_analysis.jl：不安定モード解析。compare.py：未表示状態比較。export_results.jl / analyze_results.py：保存結果の集計と図。
