# VSM外側制御：case0788の等価変換と回転検証

既存の詳細GFMモデルのPフィルタ状態をpu周波数偏差に置換し、仮想動揺方程式で内部角を生成する実装です。LCL回路、電圧・電流PI、Q–V制御、仮想インピーダンス、電流指令制限を保持します。52微分状態＋14代数変数のままで、独立したPフィルタを慣性に重ねて追加しません。

このフォルダだけで実行用ファイルを準備できる独立した実験です。リポジトリ全体の概要は[トップページ](../README.md)を参照してください。

## 含めたファイル

| 場所 | 内容 |
|---|---|
| `code/vsm.jl` | Pf↔pu周波数偏差の状態写像、VSM右辺 |
| `code/run.jl` | A～Hと代表2例の刻み幅照合、平衡点・イベント・波形の保存 |
| `code/model.jl`, `engine12.jl` | 詳細モデル読込、観測、代数整合化、固有値計算 |
| `code/analyze.py`, `audit.py`, `report.py` | 波形比較、分類、設定監査、作図・報告 |
| `code/prepare_recompute.py` | 出力の混在を避けるため空の別実行フォルダを作成 |
| `inputs/`, `data/seeds/` | 基準設定、状態対応、実行条件、平衡点候補 |
| `provenance/` | 固定依存環境とモデルソース。第三者ライセンスを含む |
| `reference_results/` | 2026-10-30に完了した10計算の小さな結果表。新しい出力ではない |
| `tables/SCR_source.csv` | SCRの既存回路値。audit.pyでも独立に再計算 |

中心例の対応値は全4機でH=27.175 s、D=50、M=54.35 sです。実コードのP–fゲインはrad/s/puなので、pu周波数への換算にωbaseが必要です。Hの実機設計妥当性は、この等価変換や有限時間計算だけでは確認できません。

大容量の軌道CSV・チェックポイント・生成図・実行ログ・論文PDFはこのGit追加に含めません。計算すると空の実行フォルダに生成されます。元の全成果物の保存先は[検証結果の文書](docs/VALIDATION.md)を参照してください。
